## Declaración de Uso de IA

### 1. Herramientas utilizadas
* **Google Gemini:** Utilizado como asistente de desarrollo  y diseño de layouts adaptables en CSS.

### 2. Etapas del proceso en las que se utilizó IA
* **Diseño de Layouts:** Planificación de tres disposiciones estructurales completamente distintas (lineal, editorial de dos columnas y grilla modular) respetando los elementos comunes obligatorios (header, nav, footer).
* **Revisión Técnica:** Auditoría de la estructura semántica de HTML5 y consistencia de unidades de medida adaptables (`rem` y porcentajes) en CSS.

### 3. Resumen de la revisión de código (Errores y Mejoras)
* **Error detectado / Implementado:** Organización de directorios deficiente. Los assets y la hoja de estilos estaban inicialmente en la raíz del proyecto. Se corrigió migrando las imágenes a `/img` y los estilos a `/css` manteniendo rutas relativas válidas.

* **Punto de mejora / Implementado:** Uso estricto de unidades relativas. Se revisaron los márgenes y contenedores para garantizar que todo el diseño se mueva a partir de `rem` y porcentajes, limitando el uso de píxeles únicamente al ancho máximo del contenedor principal (`1100px`).

### 4. Conclusiones sobre el uso de IA en el desarrollo
* **Ventajas:** Me funciono para resolver los layouts distintos de cada pagina.
* **Desventajas:** Se siente bastante inutil para ciertas actividades como creatividad y selecion de colores o distribución de textos.
